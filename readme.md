## Задание л/р

## Лабораторная работа №1. Умножение квадратных матриц

**Задача:**
Написать программу на языке C/C++ для перемножения двух квадратных матриц.

**Входные данные:**
- Файл(ы), содержащие значения исходных матриц.

**Выходные данные:**
- Файл со значениями результирующей матрицы.
- Время выполнения.
- Объем задачи (количество операций, используемая память) и др.

**Требования:**
- Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например, на Matlab/Python).

## Лабораторная работа №2. Параллельное умножение матриц (OpenMP)

**Задача:**
Модифицировать программу из л/р №1 для параллельной работы по технологии OpenMP.

**Требования к экспериментам:**
Провести серию экспериментов со следующими переменными:
- **Количество потоков:** 1, 2, 4, 8 и т.д.
- **Размеры матриц:** примерно 200, 400, 800, 1200, 1600, 2000.
- **Количество вычислительных ядер:** при наличии технической возможности (1, 2, 4, 8 и т.д.), иначе использовать фиксированное существующее количество вычислительных ядер (например, 4).
